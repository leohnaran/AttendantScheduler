# Secure Circuit Assembly Scheduler

A powerful, single-file browser application designed to streamline the scheduling of attendants for Circuit Assemblies. This tool helps manage personnel, assign shifts efficiently, and ensure a balanced workload across the department.

## Quick Start

1.  **Download** the `schedule.html` file.
2.  **Open** the file in any modern web browser (Chrome, Firefox, Edge, Safari).
3.  **Start Scheduling!** No installation or server is required.

> **Note:** An active internet connection is required to load the necessary libraries (React, Tailwind CSS, etc.) when opening the tool.

## Key Features

### 📋 Personnel Roster
*   **Easy Management:** Add, edit, or remove personnel directly in the app.
*   **CSV Import:** Quickly import large lists of brothers using a standard CSV format.
*   **Organization:** Group attendants under "Key Men" using simple drag-and-drop actions.
*   **Qualifications:** Track capabilities (e.g., Auditorium, Upper Level, Parking) to ensure the right person is in the right spot.

### 📅 Intelligent Scheduling
*   **Magic Fill:** Automatically assign shifts based on fairness logic, qualifications, and availability.
*   **Conflict Detection:** Real-time alerts for double-bookings or qualification mismatches (e.g., assigning a non-Elder to a restricted spot).
*   **Flexible Views:** View the schedule by position or shift times.

### 📊 Statistics & Balance
*   **Fairness Check:** Monitor "Minutes Away" from the program for every brother.
*   **Visual Load:** Color-coded bars help identify who is overworked or underutilized.
*   **Role Tracking:** Easily see the distribution of assignments among Elders, Ministerial Servants, and others.

### 🔒 Security & Data
*   **Local Storage:** Your work is automatically saved to your browser's local storage, so you won't lose progress if you close the tab.
*   **Encrypted Backups:** Export your schedule as an encrypted file protected by a password of your choice. Securely share the file or back it up without exposing sensitive data.
